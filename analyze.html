How This Score Is Built

methodology —

Published weights are nominal. An input a row has no value for is dropped and the remaining weights are renormalised — never imputed — so the weight an input actually carries depends on how widely it is measured. Quote the effective column.

Input Nominal Effective Coverage Status

How big a move has to be to mean anything

Measured from every consecutive month-pair in the dataset, bucketed by the smaller of the two months’ auction counts. A move under the median is what an unchanged market looks like at that sample size; clearing the 90th percentile is the bar for calling it real.

Auctions / month Median swing 90th percentile

How to Backfill Missing Data

If months are flagged above, use the CLI scripts to identify and backfill missing dates:

  1. Run the diagnostic to see all gaps across all months: node scripts/diagnose-data-gaps.js
  2. Get a pipeable list of missing dates for a specific range: node scripts/backfill-checker.js 2025-01-01 2025-01-31
  3. Pass the missing dates to your scraper's backfill command: node scripts/backfill-checker.js 2025-01-01 2025-01-31 | xargs -I{} your-scraper --date {}
  4. After re-running the scraper, regenerate mii_results_latest.csv and upload both CSVs to S3.
